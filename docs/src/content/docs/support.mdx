Contact **[support@renner.dev](mailto:support@renner.dev)** for app support and privacy requests. For a reproducible bug using synthetic data, you can also [open a GitHub issue](https://github.com/rennerdo30/sim-bridge/issues).

## Before reporting

Include your app version/build, operating system, gateway/client role, and the visible error. Explain what you expected and the steps to reproduce it. Use example messages and phone numbers. Never attach recovery codes, bridge keys, owner/device tokens, signing credentials, or a live relay database.

If sync stops, confirm the relay URL is reachable, the Android gateway is available, and the required permissions are granted. Desktop clients must remain running; closing the last window quits. For an Android gateway, inspect its gateway checks and battery/OEM restrictions. An iPhone cannot act as a physical SIM gateway or show bridged messages in Apple Messages.

## Privacy and security

[Privacy information](../legal/privacy/) explains data flow and deletion limits; [terms of use](../legal/terms/) explain authorized use and carrier responsibilities. For confidential vulnerabilities, email support@renner.dev with a brief description and synthetic reproduction. Do not post vulnerabilities containing sensitive data publicly.

## Release availability

The current project is being prepared for release. GitHub Actions account billing is blocking hosted jobs, and signed/store-approved release packages are not yet available. Documentation and screenshots show source behavior and do not establish device/store acceptance. Check the GitHub release notes for verified platform support when a release is published.
